# Modern Portfolio Card UI

A modern dark-themed portfolio card interface built using HTML and CSS.  
This project showcases stylish profile cards, social media icons, buttons, and responsive layouts with modern UI effects.

## Features
- Dark Theme UI Design
- Multiple Profile Cards
- Social Media Icons
- Stylish Buttons
- Modern Card Layout
- Box Shadows and Rounded Corners
- Responsive Flexbox Design

## Technologies Used
- HTML5
- CSS3
- Font Awesome Icons

## Project Structure
- index.html
- style.css

## Project Description
This project is designed to practice frontend web development concepts such as flexbox, positioning, card layouts, modern UI styling, and responsive design techniques.

## UI Components
- Main Profile Card
- Sidebar Navigation Card
- Social Media Icons
- Action Buttons
- Image Sections
- Interactive Layout Design

## Future Improvements
- Add animations and hover effects
- Make the design fully responsive
- Add JavaScript interactions
